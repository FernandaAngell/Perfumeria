# 🌸 Auréum Parfums - Tienda Web de Perfumería

## 🧾 Descripción

Auréum Parfums es una página web moderna de e-commerce enfocada en la venta de fragancias exclusivas.

Incluye carrito de compras dinámico, animaciones elegantes y diseño responsive.

---

## 🚀 Funcionalidades

* 🛒 Carrito de compras interactivo
* 🔍 Buscador de productos
* 🎨 Animaciones al hacer scroll
* 📱 Diseño responsive (adaptable a móviles)
* 💳 Simulación de compra

---

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

---

## 📂 Estructura del proyecto

* `index.html` → estructura principal
* `styles.css` → diseño visual
* `script.js` → lógica del carrito y animaciones

---

## 🎯 Objetivo del proyecto

Desarrollar una tienda virtual aplicando diseño moderno, interacción con el usuario y lógica en JavaScript.

---

## 💡 Características destacadas

* Diseño tipo e-commerce premium
* Uso de animaciones suaves
* Manejo dinámico del carrito sin backend
